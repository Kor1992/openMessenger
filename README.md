# OpenMessenger

Backend-сервис мессенджера на Go.

Проект находится в активной разработке. Основная цель — построить полноценный backend мессенджера с авторизацией, обменом сообщениями и асинхронной обработкой событий.

## Текущий стек

* Go 1.26
* PostgreSQL 16
* pgx
* JWT
* Apache Kafka
* golang-migrate
* Docker
* Docker Compose

## Архитектура

Проект организован с разделением HTTP-обработчиков, бизнес-логики и работы с базой данных.

```text
HTTP API
   ↓
Handler
   ↓
Service
   ↓
Repository
   ↓
PostgreSQL
```

Kafka используется как брокер сообщений для асинхронного взаимодействия между компонентами приложения.

## Основные компоненты

### PostgreSQL

Используется для хранения основных данных приложения.

Для работы с PostgreSQL используется `pgx`, а управление изменениями структуры базы данных выполняется через `golang-migrate`.

### JWT

JWT используется для аутентификации пользователей и доступа к защищённым API.

### Kafka

Kafka используется как брокер сообщений.

Текущая конфигурация проекта предусматривает отдельный Kafka broker и topic `messages`.

## Запуск

Для запуска проекта необходим Docker и Docker Compose.

```bash
docker compose up --build
```

После запуска:

* приложение — `localhost:8080`;
* PostgreSQL — `localhost:5432`;
* Kafka — `localhost:9092`.

## Разработка

Проект развивается постепенно: от базового backend API к полноценной системе обмена сообщениями.

В дальнейшем планируется расширение функциональности мессенджера и инфраструктуры обработки сообщений.

## Цель проекта

OpenMessenger используется как основной практический проект для изучения и применения backend-технологий Go.

В рамках проекта планируется отработать не только разработку REST API, но и работу с PostgreSQL, Kafka, конкурентностью, асинхронной обработкой сообщений, real-time взаимодействием и инфраструктурными компонентами.
